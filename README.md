# 📌 Project Overview

The **Netflix Analysis Dashboard** is a visually interactive **Power BI project** designed to analyze Netflix content across different dimensions such as movies, TV shows, ratings, genres, release years, and country-wise distribution.

This dashboard transforms raw Netflix data into meaningful business insights through powerful visualizations, helping users understand content trends, audience preferences, and global content distribution.
